# InsightEra

> InsightEra Co., Ltd. is a Bangkok-based marketing technology and data intelligence company building online marketing tools from social network data. It publishes one public developer surface: the NLP Platform API ("ELI"), a RESTful Thai natural-language-processing service with a live Swagger 2.0 contract covering tokenization, POS tagging, named entity recognition, sentiment analysis, spell correction, OCR, address and email extraction, clustering, and trainable custom text classification.

InsightEra did not publish an llms.txt. This file was generated by API Evangelist on 2026-08-13 from
the provider's own published Swagger contract and from live probes of its hosts.

## What is callable

- [NLP Platform API reference](https://nlp.insightera.co.th/docs/v1.0/): Swagger UI over the live contract. 23 operations. Base URL https://nlp.insightera.co.th/api
- [Swagger 2.0 contract](https://nlp.insightera.co.th/api/doc/doc.json): the machine-readable definition, served live
- [ELI Showcase](https://demo.nlp.insightera.co.th/): hosted demo application exercising the NLP endpoints

## How to call it

- Auth: a required `token` query parameter on every operation. There is no `securityDefinitions` block in the contract, no OAuth, and no scopes. Tokens are issued by InsightEra; there is no self-service signup.
- Requests are `application/json`, except `/nlp/ocr` and `/nlp/classification/train-with-file`, which take `multipart/form-data`.
- Errors return a flat `{"message": "..."}` body, not RFC 9457 problem+json, and carry no machine-readable code.
- A missing or invalid token returns HTTP 400 `Invalid session token` — not the 401 the contract documents.
- A token without quota for the requested service returns HTTP 403 `This token has no quota allowed on this service`. HTTP 403 is not declared on any operation in the contract.
- No rate-limit headers, no `Retry-After`, no request-id header, no pagination, and no idempotency key.

## Text analysis operations (tag: nlp)

- `POST /nlp/tokenize`: Thai text tokenization with a selectable engine
- `POST /nlp/pos`: part-of-speech tagging over a batch of texts
- `POST /nlp/ner`: named entity recognition over a batch of texts
- `POST /nlp/sentiment-new`: sentiment analysis over a batch of texts
- `POST /nlp/spell-correction`: spell correction for a text string
- `POST /nlp/cleaning`: text normalization and cleaning
- `POST /nlp/clustering`: cluster a sample set (engine, feature_engine, k, max_k)
- `POST /nlp/common-phrase`: top-k common phrases across a sample set
- `POST /nlp/country`: country detection, optionally with an extra dictionary
- `POST /nlp/datetime-parser-new`: parse natural-language date/time expressions
- `POST /nlp/address-extractor`: structure a plain-text Thai address into name, phone, tambol, amphoe, province, postcode plus an address-likelihood probability
- `POST /nlp/extract-email`: extract email addresses from a batch of texts
- `POST /nlp/similar`: top-N similar words for a given word
- `POST /nlp/ocr`: extract text from an uploaded image (multipart)
- `POST /nlp/qa`: question answering — marked "coming soon" in the contract, not yet available

## Custom classification operations (tag: classification)

- `POST /nlp/classification/train`: train a model from labelled data (`is_sync` controls sync/async)
- `POST /nlp/classification/train-with-file`: train from an uploaded file (multipart)
- `POST /nlp/classification/retrain`: retrain an existing model by `modelId`
- `POST /nlp/classification/predict`: predict a sample set against `model_id`
- `POST /nlp/classification/model`: model detail by `model_id`
- `GET /nlp/classification/token`: list the model ids owned by the calling token
- `POST /nlp/classification/change-model-name`: rename a model
- `POST /nlp/classification/delete`: delete a model

## Not available

- No SDKs or client libraries in any public package registry
- No MCP server, no A2A agent card, no GraphQL, no AsyncAPI, no webhooks
- No `/.well-known/` documents on any host, no security.txt
- No published pricing, no self-service signup, no free tier
- No sandbox or test environment — the try-it console runs against production
- No status page, no SLA, no dated API changelog, no deprecation policy
- The commercial SaaS products (DOM, CENT, Alice, Brian, 1Palette, GenA) have customer-only backends with no published contract
